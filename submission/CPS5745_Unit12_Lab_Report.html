Framework comparison and submission notes

Lifecycle comparison

Vanilla uses DOM listeners and pagehide cleanup. Vue watches data and filter refs, then cleans up before unmount. React and Preact use effects and refs to hand the chart node to D3. Lit connects its request lifecycle to a custom element and its reactive updates. Svelte separates mount cleanup from its reactive redraw. Solid uses signals, reactive effects, and onCleanup. Qwik binds to a visible task and uses cleanup with the client-rendered component. All share the same D3 timer disposal and preserve native UI state.

The scene encodings separate measured or published values from display geometry. A force layout, a projection, a smoothed line and particles can each make relationships easier to explore, while linked readouts provide the exact quantities used for the investigation.
